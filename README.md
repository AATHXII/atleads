# at leads — сайт

Статичный сайт at leads: https://atleads.pro. Хостинг Netlify, автодеплой из ветки `main`.

- Страницы: `index.html` (общая), `nedvizhimost.html`, `medicina.html`, `rf-target.html`, `privacy.html`.
- Заявки: Netlify Forms, форма `lead` (Netlify → Forms). В заявку пишутся страница, UTM-метки, fbclid/gclid и источник перехода.
- ID GA4, Meta Pixel и номер WhatsApp задаются в начале `assets/site.js`.
